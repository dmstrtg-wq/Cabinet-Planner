# Room references for Phase 4 (room shapes)

Real layouts Dan sends, used to design docs/ROOM-MODEL-V2.md. Each one lists what the
planner has to be able to draw, price and order.

## 01: angled sink run into a peninsula (Dan's sketch, 2026-10-20)
`01-angled-sink-peninsula.jpg`
- **Top wall, one straight run:** BMW24 (microwave base), B24 with 2 roll-out trays, 36" range with a 36" hood, DB30 (3 drawers), B18. Uppers: W1542, W3042, hood, W3042, W1542 (42" uppers).
- **Bottom wall:** B12, B30 with 2 roll-out trays, B18 with tray dividers. Uppers W3042 × 2.
- **A 45° turn in the run:** the SB36 sits on the angle, with a tapered filler or wedge on each side where it meets the straight runs.
- **The run then turns 90° and becomes a peninsula** (free end in the room): 24" dishwasher at the end, closed with a **DWP2434-1/2** (dishwasher end panel, 24 deep × 34-1/2 high).

What the planner needs for this one:
1. Runs that can turn at any angle (45° here), with cabinets placed on the angled piece, not only on room walls.
2. The joints at an angle: the wedge or filler pieces on both sides of the angled cabinet, and the countertop following the turn.
3. Peninsulas: a run that leaves the wall and ends in the room, with a finished end (here a dishwasher end panel).
4. Accessories on cabinets: roll-out trays (RT, with a count) and tray dividers (TC), priced from the price list when the supplier lists them.
5. Panel naming follows the supplier's code. The order list already uses the code saved by a price-list import, and BEP/WEP is only the fallback. The importer now reads DWP (dishwasher end panel) as a base end panel, so this one orders as DWP2434-1/2.
